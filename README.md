# Anno Tenebris

Роуглайк в ASCII-графике. Европа, 1247 год: татары прошли через Польшу и Венгрию,
в лесах снова шепчутся старые боги, на перекрёстках ждут чёрные псы, а над болотами
пляшут огни.

## Как запустить

Ничего устанавливать не нужно: откройте `index.html` в любом современном браузере
(Chrome, Firefox, Edge, Safari). Двойного клика по файлу достаточно.

## Что уже есть

**Создание персонажа**
- 7 народов: франк, русич, тевтонец, норманн, ломбардец, кастилец, ромей. У каждого свои
  поправки к характеристикам и особенность (например, у ломбардца — скидки у торговцев,
  у кастильца — дополнительный урон по нечисти).
- 4 характеристики, на которые распределяются очки:
  - **Сила** — урон и меткость;
  - **Живучесть** — здоровье, его восстановление, стойкость к яду;
  - **Мудрость** — дальность зрения (особенно ночью), знание зверей в бестиарии, цены;
  - **Вера** — благодать и молитва, которая лечит и опаляет нечисть.
- Уровни: за опыт даётся очко характеристики.

**Мир и деревни**
- Мир генерируется заново каждую игру: луга, леса, хвойные чащи, реки, болота, холмы, скалы.
- 4–5 деревень, соединённых дорогами с мостами. В каждой есть церковь, трактир, кузница,
  хижина знахарки, дом старосты, избы и колодец на площади.
- Жители:
  - **староста** даёт задания на охоту;
  - **священник** восстанавливает благодать и лечит за пожертвование;
  - **трактирщик** скупает трофеи, сдаёт угол на ночь и наливает эль;
  - **кузнец** продаёт оружие и броню;
  - **знахарка** варит целебные отвары и выводит яд;
  - **крестьяне** и **стражники** пересказывают слухи.
- Смена дня и ночи: ночью видно хуже, а звери в деревни не заходят.

**Бестиарий**
- Животные: заяц, лиса, олень, ворон, гадюка, волк, кабан, медведь. У каждого своё
  поведение: пугливые убегают, хищники охотятся, кабан и медведь защищают свою территорию,
  гадюка сидит в засаде и отравляет.
- Нечисть, которая выходит только по ночам: блуждающий огонёк, чёрный пёс, волколак.
  На рассвете она обращается в туман.
- Бестиарий пополняется при встрече со зверем. Подробности о повадках открываются после
  первого убийства или при достаточной Мудрости.

## Управление

| Клавиша | Действие |
|---|---|
| Стрелки, NumPad, `H J K L Y U B N` | ходьба (на зверя — атака, на жителя — разговор) |
| Пробел, `.`, NumPad 5 | ждать ход |
| `P` | молитва |
| `Q` | выпить отвар |
| `R` | отдыхать до восстановления |
| `C` | лист персонажа и повышение характеристик |
| `I` | котомка |
| `X` | бестиарий |
| `?` / `F1` | справка |

Команды привязаны к физическим клавишам, поэтому работают и на русской раскладке.
На сенсорных экранах появляются экранные кнопки.

## Устройство кода

Чистый JavaScript без сборки и зависимостей.

| Файл | Что внутри |
|---|---|
| `js/rng.js` | генератор случайных чисел с зерном |
| `js/term.js` | «терминал» на canvas: сетка символов, цвета, рамки |
| `js/data.js` | **все игровые данные**: народы, характеристики, снаряжение, бестиарий, имена, слухи, задания |
| `js/world.js` | типы местности, генерация мира и деревень, дороги (A*), поле зрения |
| `js/creatures.js` | игрок, звери, жители, бой, поведение, появление зверей |
| `js/screens.js` | создание персонажа, диалоги, лист персонажа, котомка, бестиарий, справка, смерть |
| `js/game.js` | игровой цикл, время суток, действия игрока, отрисовка карты и панели |

Чтобы добавить нового зверя, народ, слух или задание, достаточно дописать запись в `js/data.js`.
