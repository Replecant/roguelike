# Anno Tenebris

Ролевая игра в ASCII-графике. Европа, 1247 год: император Фридрих II воюет с папой, в Италии гвельфы
режутся с гибеллинами, за Альпами — Гельвеция и Карантания, на западе — Прованс нового графа
и разорённый крестовым походом Лангедок. А в Апеннинах воют лупо маннаро, у Роны просыпается Тараска,
и в озере Джерундо живёт змей Тарантазио.

## Как запустить

Ничего устанавливать не нужно: откройте `index.html` в любом современном браузере
(Chrome, Firefox, Edge, Safari). Двойного клика по файлу достаточно.

Игра сохраняется сама (в хранилище браузера): при входе и выходе из поселений, на рассвете
и закате, каждые сто ходов, когда вкладку закрывают, и по клавише `S`. На титульном экране
`Enter` — продолжить, `N` — новый герой, `Q` — быстрый старт (случайный народ, характеристики
и имя — удобно для проверки). После гибели можно вернуться к последнему сохранению.

## Для разработки

```bash
npm install
npx playwright install chromium
```

| Команда | Что делает |
|---|---|
| `npm run typecheck` | проверка типов (TypeScript проверяет JS-код: опечатки в именах, не те аргументы) |
| `npm test` | автотесты в браузере |
| `npm run check` | и то и другое |
| `npm run build` | собрать игру в один файл `dist/anno-tenebris.html` |
| `npm run stress -- 3` | стресс-прогон генерации на 3 случайных мирах: все поселения, уровни подземелий, глушь, события — ищет запертые места, жителей в стенах, недоступные сундуки и двери |
| `npm run soak -- 3 500` | бот-игрок: 3 героя по 500 шагов сами играют (ходят, говорят со всеми, торгуют, лезут в подземелья, сохраняются) и ищут ошибки |
| `npm run balance` | балансный отчёт: тысячи схваток четырёх профилей героя (1, 3, 5, 8 ур.) со зверями, нечистью, логовами и хозяевами подземелий; частота нападений в пути; голод и усталость; награды поручений и цены |
| `npm run arcane` | прогон алхимии и герметики: сколько алхимиков, травы по месяцам, путь ученика, удача варки по навыку, рост навыка, себестоимость зелий, все семь талисманов, благочестие, операции, сохранение |
| `node tools/audit-cities.js` | аудит поселений: предметы, перегораживающие проход, мосты и берега, одинокие колонны, крошечные и рваные дома |
| `node tools/sim-travelers.js [N]` | прогон дорог: герой идёт через север, центр, юг, Сицилию и Сардинию — сколько путников видно, сколько шаек рядом, нападений и встреч со зверями в день |
| `node tools/audit-map.js [N]` | аудит карты Италии на N мирах: мосты (дорога по воде, по руслу), места на неподходящей местности, дворы у дорог, подземелья, места вплотную, сдвиг городов от настоящих координат |
| `node tools/audit-gen.js [N]` | аудит генерации на N мирах: все поселения (входы связаны, жители, двери, колодцы и алтари достижимы; клочки пашни, поля в отрыве от жилья), сёла на карте (местность, дорога или проселок, не вплотную), одинокие пашни на карте мира, особые места и 60 диких карт (жители и тайники достижимы, можно уйти через край) |
| `node tools/sim-novice.js [героев] [дней]` | выживаемость новичка: герои создаются как в игре и сами живут первые дни (дороги, простая работа, припасы, ночлег, бой, отвары, бегство, откуп от разбойников; `PAY=0` — не откупаться); сколько гибнет, когда, от кого, с каким оружием и предысторией |

На GitHub всё это запускается само при каждом пуше (`.github/workflows/check.yml`), а собранный
файл можно скачать со страницы проверки.

`npm test -- вера` — только тесты, в названии которых есть «вера». Тесты лежат в `tests/cases.js`:
старт за каждый народ, интерфейс и мышь, все поселения (жители, входы, нет зверей), встречи у ворот, доставка,
торговля, подземелье, снаряжение, события из слухов, журнал, вера, стрельба, лошадь и мул,
календарь и погода, еда и усталость,
сохранение и загрузка.

## Что уже есть

**Создание персонажа**
- 9 народов, как их звали в 1247 году: франк, русин, немец, норвежец, итальянец, кастилец, ромей, англичанин,
  сарацин (мусульманин из Лючеры: молится в мечети, мессы и служба Церкви закрыты). Народ не даёт бонусов —
  он решает, откуда ты и как к тебе обращаются люди. Пока карта — одна Италия, путь начинается в случайном городе;
  когда появятся родные земли народов, старт будет у себя дома.
- 5 характеристик: **Сила** (урон, меткость), **Живучесть** (здоровье, стойкость к яду),
  **Ловкость** (уклонение, меткость, умение обойти зверя в пути), **Мудрость** (зрение, знание зверей, торг, сопротивление пению сирен и тарантизму),
  **Вера** (благодать, сила молитв, новые молитвы на 5–8).
- Уровни: за опыт даётся очко характеристики.

**Карта Италии**
- Построена по реальным координатам: береговая линия, Сицилия, Сардиния, Корсика, Мальта и Гоцо, Альпы, а за ними — Гельвеция и Карантания, на западе — Прованс и Лангедок,
  Апеннины, Гарган, Этна и Везувий, реки По, Адидже, Арно, Тибр и другие, озёра Гарда, Комо,
  Маджоре, Тразимено, топи дельты По, Мареммы и Понтинских болот.
  Клетка — примерно 2,5 км по горизонтали и 5 км по вертикали (≈ 425 × 276 клеток; Мальта для наглядности увеличена почти вдвое); от Милана до Рима —
  около 190 шагов и 9–10 дней пути. Масштаб задаётся одной константой `MAP_SCALE` в `content/world.js`.
- 21 регион и держава 1247 года: Генуэзская республика, Ломбардская лига, Папская область,
  Королевство Сицилия, Сардинские юдикаты и другие. У властей в каждой земле свой титул:
  подеста, консул, байюл, ректор, куратор.
- 93 города и городка, римские дороги (Аврелия, Кассия, Фламиния, Эмилия, Аппия и другие),
  морские пути между портами — только так можно попасть на острова.
- Проселки: к каждой деревне, замку и монастырю в стороне от тракта ведёт грунтовая дорога — тоньше тракта, но по ней быстрее, чем лесом или горами. Путники с трактов сворачивают на проселки к своим деревням.
- В поселение входят по дороге: с того края, откуда пришёл, если там есть дорога или тропа; пришёл полем —
  на ближайшей к этой стороне дороге; у приморского города, где дорога упирается в берег, — на ней за воротами.
- **Сардиния** 1247 года — четыре юдиката. Кальяри у пизанцев: над городом их крепость Кастель-ди-Кастро, правит
  кастелян. Ористано — столица Арбореи, последнего юдиката, что ещё сам себе хозяин. Сассари — Логудоро.
  Терранова — порт Галлуры, туда ходят корабли из Пизы и Бонифачо. Сардинская дорога соединяет все четыре городка.
  В замке Гочеано живёт Аделасия, юдикисса Торреса: император выдал её за своего сына Энцо и сделал его королём
  Сардинии, а Энцо давно уехал воевать в Ломбардию. Слухи — о юдикатах, непокорённой Барбадже, нурагах и могилах великанов.
- **Мальта** (графство Мальтийское Сицилийского королевства): лодка из Сиракузы в Биргу (день пути),
  оттуда — на Гоцо. Мдина на холме, где мусульман ещё больше, чем христиан: мечеть, каид и имам,
  рядом — церковь у грота святого Павла. Биргу у Большой гавани под замком Каструм Марис,
  Гоцо с крепостью Кастелло. Сухая земля: известняк, колючий кустарник, поля за каменными оградами.
  Слухи — о переписи брата Жильбера 1241 года, генуэзских графах-корсарах, хлопке и тмине.
  Мальтийцы говорят о своём: о воде и цистернах, хлопке на террасах, корсарах и дозорных кострах,
  о Тунисе и переписи — без италийских подест и гвельфов; и здороваются по-своему (content/voices.js — голоса земель).
  На Гоцо — Джгантия, «Башня великанов»: два храма из исполинских глыб, в глубине — плита с находкой.
  По холмам Мальты изредка бродит **великан** (не чаще раза в месяц — и у самих храмов). Медлителен,
  бьёт каменной глыбой, первым не нападает, если не подойти близко; с него — две порции мозга для отвара.
- **Гельвеция** — земли империи на стыке Швабии и Бургундии; Швейцарии ещё нет, союз лесных долин будет в 1291-м.
  Своя география: Альпы Гельвеции и Бернские Альпы, Юра, холмистое Междуречье между ними; озёра Леман,
  Невшательское, Тунское, Люцернское, Цюрихское, Боденское; Рейн, Рона, Ааре, Ройс, Лиммат.
  Девять городков: аллеманские **Базель** (собор над Рейном, мост 1225 года), **Цюрих** (Гросмюнстер и Фраумюнстер,
  Лиммат из озера), **Берн** (Часовая башня — западные ворота, петля Ааре), **Люцерн** (у озера, живёт с перевала),
  **Кур** (епископский холм, говорят по-ретороманским) и романские **Фрибур**, **Лозанна** (собор достраивают),
  **Женева** (собор Святого Петра, замок на острове посреди Роны), **Сьон** (церковь-крепость Валер).
  Знаменитые места: аббатства Санкт-Галлен и Айнзидельн, странноприимный дом Сен-Бернара на перевале,
  замки Габсбург, Кибург и савойский Шильон, деревни Альтдорф и Швиц.
  Три перевала с италийской стороны, по реальным долинам: **Большой Сен-Бернар** (Турин — Аоста — Лозанна — Женева),
  **Сен-Готард** (Милан — Комо — Люцерн — Цюрих — Базель), **Септимер** (Комо — Кур — Цюрих). Зимой горы вне дорог засыпаны.
  Деревни, замки и обители края названы по-здешнему (Мейринген, Вевей, аббатство Энгельберг, замок Грюйер), без итальянских «Рокк».
  У жителей свои имена — аллеманские (Рудольф, Ули, Верена, Регула) и романские (Вюйерм, Мерме, Перонетта);
  свои звания: шультгейс, ратсхерр, амман аббата, вицедом епископа, в деревнях — амман; не остерия, а корчма, не палаццо, а ратуша.
  Говорят о своём: о скоте на верхних лугах, сыре и соли из Сален, лавинах, вьючниках через Чёртов мост,
  о графах, епископах и аббатствах. Слухи — об отлучённых Швице и Сарнене, Цюрихе, выгнавшем клир под интердиктом,
  крестнике императора Рудольфе Габсбурге, Кибургах без наследников, Петре Савойском в Во, свободной Ури;
  предания — о Пилате в горном озере, Чёртовом мосте, шествии мёртвых в Вале. Свой товар — кожи; сыр здесь дёшев.
  В горах изредка встречается **горный змей** (из головы старого змея — драконий камень), бродят козероги, медведи и сальваны.
  Путь начинается в Италии — в Гельвецию приходят своим ходом.
- **Карантания** — земли за Юлийскими Альпами: герцогство Каринтия (герцог Бернхард Шпонхейм правит с 1202-го),
  марка Крайна и Нижняя Штирия, оставшаяся без государя после гибели последнего Бабенберга на Лейте в 1246-м.
  География: Юлийские Альпы, Караванке, Камникские Альпы, Высокий Тауэрн, Похорье, Крас; Драва, Сава, Савинья,
  Мура, Крка; озёра Вёртское, Оссиахское, Мильштетское, Бохиньское и исчезающее Церкницкое. Холмы и леса повсюду.
  Одиннадцать городков: **Филлах** (епископа Бамбергского, мост через Драву), **Санкт-Файт** (столица герцога),
  **Фризах** (архиепископа Зальцбургского, ров с водой, монетный двор, первые доминиканцы в немецких землях),
  **Клагенфурт** (герцог переносит его с болот), **Любляна** (замок над Любляницей, камни Эмоны), **Крань**, **Камник**
  (Андексы-Меранские), **Костаньевица** (на острове в Крке, монетный двор), **Целе**, **Марибор**, **Птуй** (камни Петовиона).
  С италийской стороны — Гемона на Канальской дороге и Триест (морем из Венеции — день).
  Знаменитые места: Крнски-Град с Княжьим камнем, где крестьянин спрашивает нового герцога по-словенски;
  Гурк с гробницей блаженной Хеммы, аббатства Оссиах, Стична и картезия Жича; замки Блед, пещерный Предъяма,
  Остервиц и Старый Град над Целе. Дороги: Канальская, римская на Эмону, на Триест, через Любель, Дравская.
  В сёлах — словенцы (Примож, Миклавж, Нежа, Уршула), в Верхней Каринтии — немцы (Ортольф, Вульфинг, Хемма),
  в городах и замках — вперемешку; в городах правят судьи, в сёлах — жупаны, пьют в корчме у корчмаря.
  Говорят о просе и барщине, десятине мёдом, козезах, татарах, что пять лет назад дошли до Адриатики,
  каринтийском железе и фризахских пфеннигах; слухи — о гибели Бабенберга и споре за Штирию, о сыне герцога —
  новом архиепископе Зальцбургском, о бездетных Андексах; предания — о Златороге, кресниках и ведомцах, рожаницах.
  Чужая земля за краем карты — Истрия и Хорватия, а не море. Свой товар — железо и мёд. Звери: волки, медведи,
  козероги, сальваны; редкий **Златорог** (убить — грех), **линдвурм** болот, **водяной** у рек по ночам.
  На атласе — свой лист CARANTANIA.
- **Юг Франции** — по левому берегу Роны **Прованс** (графство Королевства Арелат, земля империи; граф с 1246-го —
  Карл Анжуйский, брат короля, и Марсель, Арль, Авиньон с их подестами его не жалуют), по правому — **Лангедок**:
  Тулузское графство Раймунда VII и королевские сенешальства, разорённые крестовым походом против катаров.
  География: Пиренеи (за ними — Арагон и Каталония, чужая земля; Балеары — тоже), Корбьер, Чёрная гора, Севенны,
  Центральный массив, Альпы Прованса, Мон-Ванту; Рона, Дюранс, Гаронна, Од, Тарн, Ло, Вар; лагуны Берр, Вакарес и То,
  болота Камарга. Средиземноморский берег — гаррига.
  Прованс: **Марсель** (город, гавань, подеста, аббатство Сен-Виктор), **Арль** (арена-квартал, Сен-Трофим), **Авиньон**
  (стены срыты в 1226-м, мост Сен-Бенезе), **Экс**, **Ницца**, **Тулон**, **Оранж**, **Валанс**.
  Лангедок: **Тулуза** (Сен-Сернен, Нарбоннский замок графов, капитулы, якобинцы-инквизиторы), **Каркассон**
  (королевский сенешаль, нижний город срыт и отстраивается за Одом), **Нарбонна**, **Безье**, **Монпелье** (короля Арагона,
  школа медиков), **Ним** (арена рыцарей, Квадратный дом), **Эг-Морт** (король строит порт для похода — крестоносцы юга идут туда),
  **Альби**, **Каор**. Знаменитые места: Сенанк, Ле-Тороне, пещера Магдалины в Сент-Бом, Ле-Бо, Тараскон, Нотр-Дам-де-ла-Мер;
  Сен-Жиль, Фонфруад, Муассак, Конк, развалины Монсегюра, Керибюс, Фуа, Ластур, Рокамадур.
  Дороги: Аврелиева (из Генуи), Домициева, на Тулузу, Ронская, через Монженевр из Турина; морем — Генуя, Марсель, Эг-Морт, Нарбонна.
  Окситанские имена (Раймон, Гильем, Эскларамонда, Азалаис); в Провансе — вигье и байли, в Лангедоке — консулы и капитулы,
  в Марселе, Арле, Авиньоне — подесты, в Каркассоне — сенешаль короля; таверны и дома консулов.
  Прованс говорит о новом графе, мистрале, отгонном скоте и подестах; Лангедок — о Мюре, жёлтых крестах, инквизиторах,
  новых господах с севера и вайде. Слухи и предания: Тараска и святая Марфа, драки Роны, Алискан, четыре дочери графа,
  смерть Монфора, Безье, сокровище Монсегюра, гроб Раймунда VI, чудо в Фанжо, Дюрандаль в Рокамадуре.
  Свои товары — вайда, вино, масло, соль Эг-Морта; звери — волки, медведи, козероги, редкая **Тараска** у Роны, **драки** по ночам.
  На атласе — листы PROVINCIA и TOLOSANVM.
- **Император и папа в Провансе.** Прованс — Арелатское королевство, земля Империи (в соборе Сен-Трофим в Арле
  в 1178-м короновали Барбароссу), а папа Иннокентий IV, низложивший Фридриха на Лионском соборе, — вверх по Роне.
  Об этом говорят священники (булла о низложении с амвона), консулы (вольности по имперским грамотам), стража,
  купцы и лодочники; слухи — о походе императора на Лион, сорванном восстанием Пармы, о Венессене и о сватовстве
  к Беатрисе; вести идут по датам (до сожжения Виттории). По дорогам Прованса ходят папский нунций со свитой
  и гонец императора с письмами городам.
- Три особых места: ореховое дерево Беневенто (шабаш ведьм по ночам), Джгантия на Гоцо и озеро Джерундо
  (логово змея Тарантазио).
- Путешествие отнимает время: по дороге быстрее, через горы и топи — дольше. В пути случаются
  встречи с хищниками этой местности (ночью — немного чаще); внимательный и ловкий путник (Мудрость, Ловкость) замечает
  их издалека и обходит. Между встречами всегда есть передышка. `M` — атлас.
- Чудища из бестиариев («Физиолог», Исидор Севильский) водятся по всей Европе, но редко, по одному и лишь когда
  герой окреп: **амфисбена** (со 2-го уровня), **василиск** со смертоносным взглядом (с 4-го), **грифон** и **мантикора**
  с шипами (с 5-го), огнедышащая **химера** (с 6-го). Заказов на них новичку тоже не дают.
- **«Кошелёк или жизнь!»** Шайка, вышедшая на героя, сперва требует денег: можно откупиться (половина кошелька,
  атаману — больше, за себя и обоз — почти всё; с пустым кошельком заберут еду или товар, с нищего — тумаки), драться
  или бежать (ловкость, атлетика, конь; неудача — драка; бегство бросает подопечных). Esc — значит драться.
- **Дозоры чужих земель** ходят от города к городу и вешают пойманные шайки, как королевский дозор на юге Италии: конные слуги
  фогта (Гельвеция), дозор герцога Каринтии, сержанты графа Карла (Прованс), сержанты сенешаля (Лангедок). Разбойники на них
  не охотятся. У околицы шайка на героя не нападает — и не топчется рядом, а уходит в лес.
- **Земля катаров.** У подножия Монсегюра — **Поле сожжённых** (‡), где в марте 1244-го сожгли больше двухсот «добрых людей»:
  пепелище, обгорелые столбы, тени сожжённых, шёпот и пение. Капеллан замка Монсегюр (герою от 3-го уровня) просит проводить
  его туда: на поле он рассказывает об Авиньонете, осаде и костре, а потом служит заупокойную — герой держится рядом, пока
  тени собираются (отойдёшь — чтение встаёт). После обряда поле затихает навсегда; награда — кошель прихода, слава, благочестие.
  В горах Лангедока спрятаны две **пещеры «добрых людей»** (∩): о них не болтают, их можно только заметить в пути. Внутри —
  совершенные и верующий; можно поговорить и пообещать молчать. **Братья-инквизиторы** ходят по дорогам Лангедока (изредка —
  Ломбардии): им можно донести об убежище — марка серебра по Тулузскому собору; нарушишь данное слово — благочестие упадёт.
- Подземелья за Альпами: римские гробницы (Гельвеция и Прованс по 2, Карантания 1, Лангедок 2), митреум и рудник норикского
  железа в Карантании, серебряный рудник Чёрной горы в Лангедоке, морские гроты в каланках Прованса.
- О самых страшных чудищах края (великан Мальты, горный змей Гельвеции, линдвурм и Златорог Карантании, Тараска
  у Роны, орко, а также василиск, грифон, мантикора, химера) предостерегают местные, когда спрашиваешь о новостях:
  раз о каждом в каждой земле. Остережение ложится в журнал (‼), зверь — в бестиарий «по рассказам» (описание без
  повадок), а встретив его, герой узнаёт его сразу. Такие чудища сами на дороге не нападают: стерегут своё место
  и медленнее героя, — подошёл близко, значит, сам выбрал.
- Ведьмы и оборотни водятся по всей Европе, но в каждом краю под своим именем и со своими поверьями:
  стрега и лупо маннаро в Италии, хексе и вервольф в Гельвеции, вешча и волкодлак в Карантании, маска и лу-гару
  в Провансе и Лангедоке. Так же их зовут в слухах и поручениях; в книге о зверях перечислены все имена.
- Римские гробницы есть не только в Италии: в Гельвеции, Карантании, Провансе и Лангедоке — у руин
  Авентикума, Виндониссы, Вирунума, Целеи, Петовиона, Гланума, Немауса, Нарбона и других городов империи.
  В Карантании, как в старом Норике, — ещё и митреум (у Петовиона, Целеи, Вирунума…).
- В шайке разбойников (с 4-го уровня героя) иногда оказывается **дезертир** — бывалый солдат в кольчуге,
  вместо одного из разбойников, не больше одного на шайку. Новичка (1-й уровень) на дороге встречают не больше двух
  разбойников. Бродячий орко нападает лишь на героя от 4-го уровня, оборотень — от 3-го (логова и поручения — свои).

**Города**
- Большие города — плотная застройка: кварталы черепичных крыш, переулки, мощёные площади
  с рынком, городские стены с башнями и воротами, реки с мостами, гавани с пристанями и кораблями.
  На карте Италии они занимают несколько клеток.
- У каждого крупного города свой облик и настоящие достопримечательности 1247 года — при первом
  взгляде на них в журнале появляется короткая историческая справка:
  - **Милан** — круглые стены со рвом, Бролетто Нуово, Санта-Мария-Маджоре, Сант-Амброджо;
  - **Венеция** — острова и каналы в лагуне, Большой канал и мост Риальто, Сан-Марко, Палаццо Дожей, Арсенал;
  - **Рим** — огромные стены, внутри которых больше руин и виноградников, чем домов; Тибр,
    Святой Пётр, замок Святого Ангела, Пантеон, Капитолий, Форум, Колизей, Латеран;
  - **Флоренция** — башни знати, Арно и Понте Веккьо с лавками, Баптистерий, Санта-Репарата;
  - **Пиза** — Площадь чудес на лужайке с собором, баптистерием и уже накренившейся колокольней;
  - **Болонья** — сотня башен, Две башни, Студиум; **Верона** — Арена и Адидже;
  - **Генуя, Неаполь, Палермо, Бари, Мессина** — портовые города со своими соборами и замками
    (в Неаполе — Кастель-дель-Ово на скале в море); **Лючера** — сарацинский город с мечетью.
- Остальные города и городки строятся по общему плану, но тоже за стенами.
- В городах видно поверх крыш, а план города известен, как только входишь в ворота.

**Деревни, монастыри, замки, постоялые дворы**
- Между городами разбросано около двухсот пятидесяти поселений: деревни (`⌂`) на 7–15 дворов с огородами,
  старостой, обычно часовней, а также таверной, кузницей или знахаркой; монастыри (`†`) с аббатом, клуатром,
  кельями и аптекой; замки (`Ш`) с сеньором или синьорой, рыцарями, кастеляном и гарнизоном: большой зал с высоким сиденьем, знамёнами и столами, покои сеньора, кухня с очагом, казарма, оружейная со стойками, кладовая, капелла, конюшня; постоялые дворы (`¤`)
  прямо на тракте: двор за оградой с воротами на дорогу, дом с общим залом и комнатами, конюшня,
  колодец, поилка, коновальня, а через дорогу — часовня святого Христофора с капелланом. Старосты деревень и кастеляны тоже дают задания на охоту.
- Знать: сеньоры носят имя рода, давшего замку имя («Таддео Гвиди» в Рокке Гвиди), дают задания на логова
  и доставки, знают военные новости издалека. В исторических замках — исторические лица: в Кастель-дель-Монте
  юный Манфред, сын императора и князь Тарантский; в Мельфи — юстициарий императора; в Каноссе — род да Каносса.
- Среди них настоящие места: аббатства Монтекассино, Ассизи (базилика Святого Франциска),
  Бобьо, Помпоза, Фарфа, Сакра-ди-Сан-Микеле, замки Кастель-дель-Монте, Мельфи и Каносса.
- Жители: власти города, священник, хозяин остерии, кузнец, травница, стража и горожане.
  Корабельщик в портах возит на острова.

**Местные карты**
- Сойдя с дороги или встретив кого-то в пути, попадаешь на подробную карту этой местности:
  если рядом море — на карте будет берег, если через клетку идёт река или дорога — они будут и здесь.

**Атлас**
- Клавиша `M` открывает карту Италии в духе средневекового атласа: пергамент, чернильные горы
  и леса, латинские названия земель и морей, роза ветров, корабль и морской змей.
  Атлас листами: ITALIA, HELVETIA, CARANTANIA, PROVINCIA и TOLOSANVM. Открывается лист того края, где стоит герой; `Tab` (или ← →) — другой лист.
  На листе Италии Гельвеция закрашена как чужие земли, на листе Гельвеции — крупно, с перевалами, соседями
  (BVRGVNDIA, SVEVIA, SABAVDIA, RAETIA) и списком тех, кто правит краем: графы, Савойя, епископы, аббатства, вольные долины.

**Деньги**
- Жизнь в дороге недёшева: паёк — 4 монеты, горячий обед — 4, ночлег — 6 (с конём 9), отвар — 11, исцеление у священника — 8; а меч стоит 260, кольчуга — 315,
  чешуйчатый доспех — 490, генуэзский арбалет — 490, мул — 160, верховая лошадь — 420.
- Подземелья скупее: монет в сундуках и саркофагах вдвое меньше; трофеи торговцы берут за полцены
  (травница — алхимические за три четверти), снятое снаряжение — за пятую часть (кузнец — за 30%).
  Торговля (навык) поднимает эти цены.
- Рынок отзывается на сделки: каждая купленная штука товара поднимает цену в этой лавке на 2,5%,
  каждая проданная — роняет; за несколько дней цены возвращаются. Выгоднее возить понемногу.
- Скупщик никогда не платит больше 90% того, за что сам продаёт то же самое — ни за товар, ни за вещь, ни на ярмарке:
  как ни торгуйся (Мудрость, навык торговли, святой Николай или Антоний, письмо Леонардо), «купил — тут же продал» —
  всегда в убыток. Зарабатывают перевозкой: лучший путь (шёлк из Лукки в Парму) — около сотни монет за день пути.
- Реликвии дороги и только для набожных христиан: чётки — 70 (благочестие от 15), зуб святой Аполлонии — 180
  (от 30), ладанка с мощами — 260 (от 40). Сарацину святынь не продают.

**Навыки и предыстория**
- Навыки растут от дела, уровни 0–10; чем выше Мудрость, тем быстрее учение. Лист героя (C) — третья колонка.
  - Бой: клинки, топоры и булавы, древковое, луки, арбалеты, метание — каждые 2 уровня +1 к меткости,
    каждые 3 — +1 к урону этим оружием; щит — уклонение со щитом; доспех — тяжёлое меньше мешает
    уворачиваться, на 5 и 10 уровне +1 к защите. Учатся в бою (щит — когда удар отбит, доспех — когда попали).
  - Странствия: выживание (медленнее голодаешь, находишь еду на привале, на ночлег реже нападают; учится
    в глуши и на привалах), атлетика (+2 груза за уровень, меньше устаёшь в пути, ловчее с ловушками; учится
    в пути), плавание (в реки, озёра, каналы и море у берега можно войти и плыть; риск захлебнуться падает
    с навыком и растёт с весом доспеха и поклажи; брод на карте Италии может сбить с ног).
  - Скрытность: ничего не подозревающий зверь замечает позже (−1 к его зрению за 2 уровня), удар
    по нему — исподтишка (урон ×1,5 и больше), в пути реже нарываешься на зверя. Учится, когда крадёшься рядом с ними.
  - Верховая езда: с лошадью или мулом быстрее и легче в пути, на ночлеге животное реже уводят. Учится в седле.
  - Люди: торговля (−1,5% к ценам покупки и +1,5% к продаже за уровень; учится на сделках);
    красноречие (выторговываешь +5% награды за уровень, чаще слышишь слухи о тайных местах; учится в разговорах);
    грамота (без неё латинских надписей не прочесть; грамотный находит в надписях указания на тайники,
    понимает латынь мессы; учится у священника или имама за плату, раз в день, и чтением надписей).
- При создании героя — предыстория: наёмник, охотник, пастух-горец, моряк, приказчик, городской стражник,
  лесоруб, монах-переписчик, нотарий, конюх, вор, жонглёр, паломник. Каждая даёт навыки и немного вещей.
- Оружие в дорогу — одно, на выбор: **дубина** (крепче всего бьёт) или **нож** (из засады на треть сильнее; дешевле
  дубины — разница остаётся в кошельке, +12 мон.). Пращи на выбор нет: вплотную она бесполезна. Её носит в мешке
  пастух-горец, а купить можно у любого кузнеца, даже сельского (12 мон.).
  Кроме того у всех — факел; оружие предыстории (лук охотника, топор лесоруба) — сверх этого.
- При гибели на могиле пишут, как тебя запомнят, — по славе: безвестного забудут к весне, известного вспомнят
  в тавернах, о знаменитом жонглёры споют, как он одолел кого-то, а прославленного занесут в хроники.

**Задания о святынях** (у священников)
- *Святыня для храма.* Пастухи нашли неподалёку старую римскую гробницу, заброшенный склеп или пещеру отшельника —
  там, говорят, мощи святого. Место отмечается на карте: это малое подземелье в один уровень, без хозяина.
  В дальнем зале — два одинаковых свинцовых ларца и расхитители могил. Один ларец подлинный, другой — подделка.
  Первый шаг к ларцу — осмотреть: грамотный (Грамота от 2) читает надпись, неграмотный выбирает наугад.
  Взял один — второй рассыпается. Подлинные мощи: награда, опыт, благочестие; подделку священник распознает и даст четверть.
- *Ограбление святыни.* Воры унесли ларец из ризницы. Священник описывает их (сколько, главарь — «рыжий верзила
  со шрамом», «хромой в краденой рясе»…), куда ушли и где прячутся — но на карте стоянка не отмечена. Её надо найти:
  бродить в тех местах и осматриваться (Enter); разыскиваемую стоянку видно за две клетки, Выживание помогает.
  Главарь — по приметам. Одолел воров — ларец в их сундуке; вернул — награда и благочестие. Срок — 10–15 дней.

**Слава**
- Известность героя (лист героя, C): безвестный → известен в округе (10) → о нём говорят в тавернах (30)
  → о нём поют жонглёры (55) → прославленный (80).
- Растёт от подвигов, о которых рассказывают: хозяин подземелья (+6), голова атамана (+5), победа на турнире (+8)
  и на ярмарке (+3), отбитый набег (+4), логово или возвращённые мощи (+3), сопровождение (+2), Дит (+15),
  аудиенция у папы (+12), «Тихая деревня» (+8). Обычные поручения — +1. Подвиг в глуши или под землёй — на треть меньше.
  Падает от провалов: брошенные подопечные (−3), опоздание или отказ (−1).
- Что даёт: знаменитого узнают на улицах («Ты не тот ли, кто…?»), жонглёры поют о нём песни, за работу платят
  щедрее (до +24%), мелкие шайки разбегаются, услышав имя (от 55). Сеньоры не дают поручений безвестным (нужно 10),
  император Фридрих — только тому, о ком говорят в тавернах (30): письмо королю Энцо в Кремону за золотые августалы.

- **Секреты** на каждом уровне (js/secrets.js):
  - *Ловушки* (`^`, когда замечены): волчья яма, отравленный дротик, ядовитые испарения, обвал,
    сигнальные колокольцы (будят всех). Замечаешь в двух шагах — помогают Мудрость и Ловкость;
    ловкий успевает отпрыгнуть. Шаг на замеченную ловушку — попытка обезвредить (Ловкость).

  - *Сокровищница* за запертой решёткой (`#` голубая); бронзовый ключ (`⚷`) лежит где-то на уровне.
    Решётку можно и выломать (Сила), но грохот слышат все.
  - *Надписи на стенах* (`≡`) — свои у каждого типа подземелий: эпитафии, знаки первых христиан,
    записки пропавших расхитителей.

**Язычники и путь в подземный мир**
- В глухих горах и лесах (Абруццо, Калабрия, Сардиния, Тоскана, Эмилия, Кампания, Сицилия) прячутся четыре
  селения язычников (`Ψ`) — потомков римлян, так и не принявших крест: римские имена, святилище с алтарём
  подземным богам, жрец-фламин. Их, как подземелья, находят случайно или по слухам; мирских новостей там не знают.
- Сицилийцы шепчутся, что под Этной вход в преисподнюю — и путь знают только старые люди в горах.
- Цепочка фламина: принести в дар подземным богам трофей хозяина любого подземелья (−6 благочестия;
  Михаил и Бенедикт этого не простят) → добыть **золотую ветвь** в пещере Сивиллы в Кумах (её стережёт
  пёс Гекаты) → вернуться к фламину, и он откроет **жерло Этны**. Без ветви туда не войти.
- **Мегаподземелье под Этной** — шесть кругов: Жерло (лава, саламандры), Кузни Вулкана (киклопы), Поля
  асфоделей (тени умерших), Берега Стикса (страж — Цербер), Тартар (эринии), Чертог Дита. На дне — Дит,
  владыка мёртвых, и сокровищница Отца богатств со Шлемом Плутона. Путь в журнале — сквозным заданием (`✶`).

**Непобедимое Солнце** — таинство Митры
- В первом митреуме, куда спустишься, у входа бродит дух Гая Валерия — гелиодрома, убитого, когда христиане
  разоряли святилище. Таинство прервали, бык не заклан, и дух не может уйти. Он ведёт по ступеням посвящения:
  - Ворон — священная трапеза: хлеб (провиант) и вино (бочонок с рынка);
  - Воин — венец на острие меча: принять его — провал («Митра — мой венец», как писал Тертуллиан);
  - Лев — очищение рук: не водой, а мёдом (лев — огонь); мёд продаёт травница;
  - на дне у рельефа — зажечь факелоносцев: Кавта (`↑`, восход), потом Каутопата (`↓`, закат);
  - из тьмы выходит белый бык Митры — его нужно заклать.
- Ошибся — дух ждёт до завтра. Подсказки — в его рассказах («Кто такой Митра?»).
- Награда — благословение Непобедимого Солнца навсегда: свет +2, меткость +1, урон по нечисти +1.
  Но это языческое таинство: благочестие −8, Михаил и Бенедикт не простят. Тому, кто служит легату, дух не откроется.

**Последние язычники** — путь, противоположный пути фламина
- Набожному герою (благочестие от 50) священник в ответ на «Нет ли для меня работы?» может предложить службу — среди обычных поручений — и пошлёт в Витербо к папскому
  легату — кардиналу Раньери Капоччи (исторический легат в Тоскане и Патримонии в 1240-х).
- Легат не знает, где они: до курии доходят только слухи. По донесениям селений четыре, и он называет
  края — «в горах Абруццо, в лесах Калабрии…». Искать самому: смотреть по сторонам в глуши (Enter —
  осмотреться) и расспрашивать местных. Дорогу к язычникам никто не укажет. Найденное селение
  записывается в журнал. В каждом нужно опрокинуть алтарь в святилище
  (два шага в алтарь: первый — предупреждение). Мирные жители бегут в лес, а фламин и стражи рощи берутся за оружие.
  Когда защитники пали, селение становится пепелищем (`×` на карте).
- После последнего селения легат даёт 150 мон. и шлёт в Перуджу, где героя принимает сам папа
  Иннокентий IV: **копьё со стягом святого Петра** (двуручное, 4–11, +2 к меткости, +3 по нечисти, +1 к Вере),
  500 мон., благочестие +15 и прозвание «Защитник веры». После аудиенции папа уезжает в Лион,
  а легат покидает Витербо.
- Выбор необратим: кто приносил жертвы подземным богам, тому легат не доверит службу; кто взялся за
  поручение, тому фламин не покажет дорогу к Этне.

**Лючера**
- Город сарацин, которых Фридрих II переселил сюда с Сицилии, — по-своему мусульманский. Имам не торгует
  реликвиями и не служит мессу: он рассказывает о вере и общине, зовёт лекаря при мечети, принимает
  милостыню (раз в неделю это зачтётся и христианину). В мечети вместо алтаря михраб.
- Свои титулы (каид, сарацинские лучники, лекарь, хозяйка харчевни), приветствия, разговоры, слухи
  (о Египте, Тунисе, походе Людовика, лучниках под Пармой); в харчевне — кускус и шербет вместо эля и вина.
- Имам даёт свои поручения (книга Ибн Сины, письмо в канцелярию), и христианских грузов ему не возят.

**Тихая деревня** — расследование в духе лёгкого хоррора
- Это дело — среди обычных поручений: на «Нет ли для меня работы?» кастелян замка может пожаловаться на ближнюю деревню
  (только опытному герою — с 4-го уровня): стала странной и закрытой,
  десятину не платит, священник пропал, урожай — на зависть.
- В деревне все холодны и уклончивы, священника нет, по улицам ползут шёпоты: ребёнок поёт задом наперёд,
  знаки углём на дверях, гул из-под земли. Лишние вопросы («Где ваш священник?») и шум злят жителей;
  разозлишь всерьёз — они молча достанут серпы и ножи.
- Если заночевать в деревне (у старосты, в таверне, прямо на земле), скорее всего, тебя утащат во сне и бросят
  в пещеры под деревней — без оружия; оно в сундуке культистов где-то рядом.
- На отшибе — запертая церковь с кладбищем (дверь — выломать, но грохот слышит вся деревня). Алтарь осквернён;
  если сдвинуть его — спуск в пещеры: бесы, одержимые селяне и глава культа — пропавший настоятель Ансельмо.
- Убил его — деревня очнулась; кастелян платит 220 монет, опыт и благочестие.

**Путники на дорогах**
- По карте Италии идут путники — каждый своим путём, по дорогам, от места к месту:
  паломники `p` (к мощам в Рим, Бари, Падую, Венецию, Ассизи, Монте-Сант-Анджело, Монтекассино),
  крестьяне с повозкой `p` (из деревни на ближний рынок), купеческие обозы `c`, нищенствующие братья `f`,
  гонцы `g` (быстрые), а пока идёт осада — имперские отряды `s` под Парму.
- На юге, в Сицилийском королевстве, гвельфов и гибеллинов нет — по дорогам ходят люди короля-императора,
  и они ни у кого не спрашивают, за кого ты: королевский дозор юстициария `k` (подскажет, где бродит шайка;
  покажешь, где засели разбойники, — накроет их и заплатит), сарацинские лучники из Лючеры `a`
  и братья-госпитальеры `h`, идущие к портам Бари, Бриндизи и Мессины, чтобы плыть в Акру
  (можно пожертвовать на их госпиталь). Шайку, что попалась дозору или лучникам на дороге, вешают на месте.
- Сколько их — зависит от земли вокруг: в глубине Италии вокруг героя около 18 мирных групп и 4 шайки,
  на Сицилии и Сардинии втрое меньше, на Мальте — разве что одна повозка. Шайки, оставшиеся далеко
  позади, рассеиваются (кроме атаманов).
- Изредка отряд гвельфов, гибеллинов или имперцев сам останавливает путника: «Стой! Кто таков?» — не чаще раза в несколько дней.
- Днём их видно издалека, ночью — только рядом. Наведи — кто это и куда идут.
- Встреча в пути игру не останавливает: в журнале — «Рядом: паломники. Enter — заговорить».
  Enter на соседней клетке — подойти. Первый разговор с группой начинается со сценки с выбором
  (поделиться провиантом с паломниками, вытащить застрявшую повозку, ответить сержанту отряда «за кого ты»:
  своих пропускают (изредка зовут на час к костру — миска похлёбки), чужим — требуют пошлину: заплатить или отказать и драться). «Пройти мимо» — идти дальше.
- У каждой группы свой нрав: торгует с воза лишь каждый третий крестьянин (остальные везут всё на рынок),
  обоз показывает товар не всегда, повозка застревает редко, голодные паломники и братья встречаются не каждый раз —
  и помочь можно, только если помощь и правда нужна.
- Если на одной клетке несколько дел (город и путники у ворот, две группы путников), Enter открывает выбор:
  «Войти: Павия», «Заговорить: купеческий обоз», «Заговорить: паломники».
- Разговор: новости дороги, жизнь в пути; у крестьян — купить
  припасов дешевле, чем в городе; у обоза — товар; с паломниками — помолиться (благодать); у братьев —
  благословение (раз в неделю).
- Разбойничьи шайки `b` рыщут у дорог (их видно только вблизи) и подкрадываются к добыче. Ограбленный обоз
  превращается в событие на карте («Разграбленный караван»), охрана иногда отбивается — об этом говорят люди.
  Подойдут к тебе — нападут (Скрытность помогает разминуться).
- Защита нужна не всем: только на дальнюю дорогу (больше 40 км), и то у обоза часто своя стража (у большого — почти всегда),
  а паломники нередко идут толпой. Решается один раз для каждой группы — переспрашивать бесполезно.
- *Охрана обоза.* Купцу на дороге можно наняться в охрану до его города (плата — по расстоянию). Обоз идёт
  с тобой, пока ты рядом (отстал — ждёт). В пути на обоз нападают: перебей разбойников — идёте дальше; уйдёшь
  с поля боя — обоз ограбят, задание провалено. Дошли — плата и опыт.
- *Сопровождение паломников.* То же с паломниками до святыни: платят немного, зато благочестие и полная благодать.
- *Атаманы.* Изредка шайку ведёт знаменитый атаман (Гвидо Железный Зуб, Беппо Одноглазый…): на всю Италию
  не больше двух, далеко друг от друга, новый — не чаще раза в три недели. Сильный
  боец в кольчуге. По округе ходит весть, что за его голову обещана награда. Сразил — голова в мешке;
  отнеси подесте или старосте любого поселения — 120–220 монет.

**События мира: ярмарки** (js/happenings.js — общий механизм событий, ярмарка — первое из них)
- Большие города держат ярмарку в день небесного покровителя: Венеция — святого Марка, Генуя и Флоренция —
  Иоанна Крестителя, Рим — Петра и Павла, Бари — Николая, Падуя — Антония, Пиза и Сиена — Успение,
  Неаполь — Януария, Болонья — Петрония, Милан — Амвросия, Феррара — Георгия. На большие праздники
  ярмарки бывают и в городках (одна — неподалёку от героя); иногда ярмарка открывается и без праздника.
- Весть о ярмарке идёт за неделю; на карте при наведении на город видны даты. К ярмарке стягиваются
  обозы и крестьяне.
- Три дня ярмарки: товар дешевле на десятую часть, продать — дороже на десятую, запасы вдвое больше;
  три заезжих купца берут трофеи дороже обычного; жонглёр поёт о Роланде и Тристане (1 мон.);
  глашатай зовёт на состязания — лучников (Луки/Арбалеты, Ловкость), борьбу (Сила, Атлетика)
  и скачки (нужна лошадь; Верховая езда). Взнос, приз, каждое — раз за ярмарку.
- В толпе карманники: раз за ярмарку могут срезать кошель (Скрытность и Мудрость помогают уберечься).
- Прочие события — редкие: одновременно не больше двух (ярмарки не в счёт), новое начинается в среднем
  раз в две-три недели где-то в Италии (половина — в краях героя), у каждого вида свой долгий перерыв,
  в одной области — одно событие. О каждом идёт весть; при наведении на город на карте видно, что там.
  - *Мор* (10–18 дней): пустые улицы, можно заразиться лихорадкой, еда дороже; у священника и травницы — помочь
    больным (раз в день: немного денег, опыт, благочестие, но риск заразиться).
  - *Турнир* в замке (весть за 5 дней): герольд зовёт на конную сшибку (нужна лошадь; Верховая езда, Древковое,
    Сила, доспех) и пеший бугурт (оружейный навык, Сила, доспех). Приз — серебро и слава.
  - *Крестный ход* (2 дня): пройти с ним — благочестие, полная благодать, а иногда — исцеление.
  - *Казнь на площади* (весть за 2 дня): осуждённый в исповеди выдаёт тайник шайки (место на карте);
    можно ночью попытаться его освободить (Скрытность) — или нарваться на стражу.
  - *Набег мародёров* на деревню (5–8 дней): перебей их — староста заплатит.
  - *Неурожай* в области (3–5 недель): хлеб почти вдвое дороже, разбойников на дорогах больше.

**Осада Пармы** (1 июля 1247 — 18 февраля 1248)
- Путь начинается 1 июля 1247 года: Парма отпала от императора 16 июня, и Фридрих II встал под её стенами.
- Рядом с Пармой — Виттория, город-лагерь императора («Победа»): там сам Фридрих II (справка — значок «i»).
- Днём в осаждённую Парму не пройти. Ночью можно пробраться через линии осады (Скрытность и Ловкость);
  не повезло — нарвёшься на дозор имперских латников. Внутри голод: хлеб и прочая еда втрое дороже,
  остальное — дороже в полтора раза. Привезти зерно — хороший заработок.
- 18 февраля 1248 года, пока император охотился, пармезанцы взяли и сожгли Витторию: весть разносится по всей
  Италии, в хронике — запись. Виттория становится пепелищем (`×`), Парма открыта и празднует; разговоры
  об осаде сменяются рассказами о победе, Кортопассо с короной императора и гибели Таддео да Сесса.

**Вход в поселения** — с края местной карты, с той стороны, откуда пришёл, у дороги, ближайшей к площади.

**Новости и разговоры**
- Мир живёт сам: каждые несколько дней что-то случается — нехватка соли в одном городе, караван
  с пряностями в другом, ярмарка, пожар, лихорадка в деревне, волки, разбойники на дорогах, смерть
  епископа, чудо в аббатстве, война двух коммун. Торговые события меняют цены у торговцев.
- В начале игры уже известны события лета 1247 года: осада Пармы, папа в Лионе, крестовый поход
  Людовика Святого, бесчинства Эццелино в Падуе.
- Кто что знает, зависит от того, кто рассказывает и где живёт: купцы и корабельщики знают
  торговые вести со всей Италии, священники — церковные, стража и кастеляны — военные,
  трактирщики слышат от постояльцев, а деревенский крестьянин знает только то, что случилось рядом.
- Один человек расскажет за день одну весть (трактирщик, купец, корабельщик — две; красноречивому — на одну больше),
  дальше — «Да я тебе уже всё рассказал. Приходи завтра». За новостями — к разным людям и в разные дни.
- У каждого жителя свой небольшой запас: две-три старые байки или страшилки (у болтунов — четыре) и
  несколько своих забот о жизни. Рассказанные слухи он не повторяет, а «Как жизнь?» отвечает раз в день —
  дальше «Да всё так же». Чтобы услышать больше, нужно говорить с разными людьми.
- «Как жизнь?» — бытовые разговоры: подати, цены, соседи, пост, жалованье, уголь. Жители замечают
  твои раны, доспех и то, откуда ты родом. Приветствие зависит от времени суток.
- Работа есть не всегда: житель может сказать, когда заглянуть, а после выполненного задания
  какое-то время ничего нового не предложит.

**Вера (католичество)**
- Благочестие (0–100): от грешника до праведника. От него и от Веры зависит, услышат ли молитву.
  Его не купишь:
  - лепта — раз в неделю в одном храме, считается доля кошелька (десятая часть, четверть, половина),
    а не сумма; у бедняка «всё, что есть» стоит почти как половина у богача;
  - воскресная месса (утром, у священника) — +2 и полная благодать;
  - молитва у алтаря (шаг на алтарь) — раз в день, половина благодати, +1 только до 40;
  - паломничество к мощам святого — +5 за каждое святилище;
  - без храма и молитвы больше двух недель благочестие понемногу тает (1 в неделю, не ниже 10); грехи: вскрытые саркофаги, языческие обереги
    (горгонейон, золотая булла — каждый день, пока надеты), опоздание с доставкой, отказ от взятого дела.
- `P` — молитвы мирянина: исцеление и изгнание нечисти. Остальные (свет веры, благословение
  оружия, покров Богородицы, молитва путника) откроются в духовных орденах.
- Святой покровитель обретается паломничеством к его мощам (благочестие от 25; смена — вдвое
  меньше благочестия): Георгий — Венеция, архангел Михаил — Монте-Сант-Анджело на Гаргано,
  Франциск — Ассизи, Бенедикт — Монтекассино, Николай — Бари, Антоний — Падуя, Христофор — часовня
  при любом постоялом дворе (у капеллана), Мария Магдалина — пещера её покаяния у Сент-Бома в Провансе
  (милость — за исповедь и милостыню; грехи отнимают вдвое меньше благочестия; чудо «Слёзы покаяния»: благодать,
  раны, дурная молва; праздник 22 июля), Марфа — мощи в Тарасконе (милость — за убитых чудищ и накормленных
  голодных странников; голод на пятую часть медленнее; чудо «Кропило и крест»: самый сильный зверь в поле зрения
  12 ходов бьёт на треть слабее и медлит; праздник 29 июля). К Святым Мариям в Камарге (Нотр-Дам-де-ла-Мер) ходят паломником —
  покровительства там не выбирают, но молитва у моря возвращает благодать.
- Святой даёт постоянную милость, а чудо — за 10 очков милости, которую копят угодными ему делами
  (Николаю — доставки и плавания, Франциску — пожертвования и помощь людям, Михаилу — изгнание
  нечисти и т.д.). У некоторых святых есть запреты: Франциск не прощает убийства мирных зверей,
  Бенедикт — разорения могил, Михаил — языческих оберегов. Нарушишь — милость сгорает.

**Спросить дорогу**
- Меток на карте нет — дорогу спрашивают у людей. Если взято задание, в разговоре появляется
  «Как добраться до Витербо?» (до города доставки, логова, легата, папы, Кум, Этны…).
- Ответ — по-старому: сторона света, сколько дней пешком, по каким римским дорогам и через какие города:
  «Ступай по Виа Аврелия до Витербо через Лукку, Пизу, Сиену». Близкое место просто покажут рукой.
- Кто сколько знает: купцы, корабельщики и трактирщики — всю Италию; рыцари, знать и священники —
  далёкие края; стража и кузнецы — ближние города; крестьянин — только до соседнего города
  («а дальше спроси у людей»). О тайных местах говорят неохотно. За море — только кораблём.
- Услышанное записывается в журнал при задании: что сказали и кто.
- В атласе (M) подписаны и городки — чтобы было по чему сверяться.

**Слухи, события на карте и журнал**
- Иногда житель рассказывает не общую весть, а наводку на место поблизости: «к югу от деревни
  такой-то, в полудне пути...». Место отмечается на карте Италии и на атласе знаком `!`.
- События: разграбленный караван (разбойники и ящики с товаром), лагерь разбойников (атаман
  и сундук с добычей), волчье логово (матёрый вожак и кости пропавших путников), старый клад
  тамплиеров (сундук стерегут мертвецы), хижина святого отшельника (исцеляет и благословляет),
  следы лупо маннаро (оборотень выходит только ночью).
- Логова чудищ: логово орко-людоеда (с одичалыми псами), разорённое кладбище (упыри и неупокоенная
  душа), гнездо ламии у заводи (с гадюками), ведьмин круг (ведьмы и чёрный пёс — только ночью),
  берлога медведя-шатуна. В логове — добыча: кошели съеденных путников, снаряжение, ведьмина мазь.
- О месте не обязательно слышать: проходя рядом, его можно заметить самому (Мудрость; Enter
  «осмотреться» — внимательнее). Такая запись в журнале — «видел своими глазами».
- Каждое событие живёт 6–15 дней, потом исчезает — кто не успел, тот опоздал. Новые появляются сами.
- О месте рядом знают окрестные жители; лучше всех — трактирщики, купцы и стража.
- **Хроника** (журнал, вкладка 4): летопись пути по дням — начало, первые посещения городов и знаменитых мест,
  уровни, первые победы над сильными тварями и нечистью, хозяева подземелий, выполненные задания,
  найденные подземелья, паломничества и покровитель, покупки, зачищенные места из слухов и смерть.
  Сверху — сводка: дни в пути, уровень, города, задания, хозяева, сражённые. После гибели — `H`.
- Журнал (`Ж` / `O`): вкладка «Задания» — кто дал, откуда, сроки, ход и награда; вкладка «Слухи» —
  всё услышанное: от кого и когда. Вести устаревают через три недели, наводки — когда место исчезло,
  проверенные отмечаются, а поверья (предания) не стареют.

**Задания**
- Работу дают старосты и власти городов, кастеляны, священники, трактирщики, кузнецы и травницы.
  У каждого жителя — одно задание за раз, всего можно взять шесть.
- **Охота** — убить зверей, что водятся в округе в эту пору года (зимой на гадюк и медведей не посылают, на Мальте — на разбойников), и вернуться за наградой. Так же и заказы замка.
- **Заказ замка: трофеи** — только в замках (кастелян; сеньор — если о тебе уже слышали): волчьи шкуры на полы
  и постели, лисий мех на приданое, оленья кожа шорнику, кабаньи клыки на рукояти, медвежья шкура к очагу,
  рога козерога или муфлона на кубки и охотничьи рога. Просят то, что водится в округе; трофеи падают со зверя —
  их надо подобрать. Платят примерно вдвое против купцов. Набрал — журнал и компас подскажут, куда нести.
- **Доставка** — отнести письмо, бочонок вина, ларец с мощами, подковы или снадобье в другое поселение
  (не дальше дня-двух пути). Платит получатель; опоздаешь со сроком — получишь половину.
- **Помощь на месте** — работа появляется прямо на карте, и на неё нужно наступить: сжать рожь (`¶`)
  и собрать виноград (`♦`) в деревне, нарубить сухостоя (`¥`) в лесу, собрать травы (`ψ`) за стенами,
  разобрать завалы (`&`) на улицах города, натаскать камней (`•`) для стены замка.
  За стенами водятся звери, так что даже жатва бывает опасной.
- **Логово** (сложное) — староста деревни, городка или замка либо священник указывает логово рядом:
  орко-людоеда, медведя-шатуна, волчью стаю, шайку разбойников, ламию (у старост); упырей на кладбище,
  ведьмин круг, лупо маннаро (у священников). Логово появляется на карте (`!`) и ждёт до конца срока
  (8–14 дней). Зачистишь — возвращайся за наградой (50–120 монет и много опыта); не успеешь —
  тварь уходит, задание проваливается. В журнале — срок и расстояние до логова.
- Опасные логова дают не всякому: волчью стаю и упырей — со 2-го уровня, медведя, ламию, ведьм и оборотня — с 3-го,
  атамана с шайкой — с 4-го, орко — с 5-го.

**Снаряжение**
- Десять слотов на теле: шлем, нагрудник, наручи, поножи, сапоги, правая рука, левая рука
  и три реликвии. Остальное лежит в мешке; экран `I` — надеть, снять, выбросить.
- Оружие: нож, дубина, топор, булава (сильнее по нежити), рогатина и двуручная секира (заняты обе руки),
  меч, римский гладиус. Левая рука: баклер, щиты, римский скутум, кинжал или факел.
- Доспехи от кожаного шлема до топфхельма (он сужает обзор), от стёганки до чешуйчатого доспеха
  (тяжёлые мешают уворачиваться). Высокие сапоги ускоряют путь по Италии.
- Из римских гробниц — снаряжение легионера: гладиус, скутум, галея и **римский доспех** (стальные полосы
  на перешитых ремнях: защищает почти как кольчуга, но сковывает). Его не продают — только находят: чаще всего
  на наместнике в богатом саркофаге. Кто видит тебя в римском, дивится — каждый по-своему и один раз:
  крестьянин крестится, кузнец разглядывает заклёпки, священник напоминает, что доспех снят с язычника.
- Свет под землёй — только факел в руке (или Свет Солнца, золотая ветвь): без огня видно лишь на шаг вокруг, факел в котомке не светит.
- Под землёй можно и поспать, если устал: в нише, спиной к стене. Сон неглубок, а обитатели подземелья бродят — могут найти спящего.
- Реликвии: ладанка с мощами (Вера), чётки (благодать), зуб святой Аполлонии (яд), подкова из
  холодного железа (дивные), медвежий коготь (Сила); из саркофагов — горгонейон (нечисть),
  золотая булла (Мудрость), перстень сенатора (цены).
- Кузнецы продают оружие и доспехи (в деревне простое, в городе лучшее), священники — реликвии,
  травницы — обереги. Разбойники, скелеты легионеров и орко иногда роняют снаряжение.

**Календарь, времена года и погода**
- Юлианский календарь: путь начинается 1 июля 1247 года, на панели — дата и день недели.
  В журнале (`Ж`, вкладка 3) — месяц, восход и закат, ближайшие праздники.
- Праздники: Рождество, Пасха и пасхальный круг (по юлианской пасхалии), Богоявление, Сретение,
  Успение, Все святые, Поминовение усопших (ночью нечисти вдвое больше) и дни святых-покровителей.
  Мессу служат по воскресеньям и праздникам; в день своего святого молитва в храме даёт +3 милости.
  Жители поздравляют с праздником.
- Долгота дня меняется: летом светло с пяти до девяти, зимой — примерно с восьми до пяти.
- Зима: снег на севере и в горах, путь через горы почти вдвое дольше, перевалы в Альпах вне дорог
  закрыты, ночёвка в поле выстуживает; волков больше, змеи, тарантулы и медведи спят.
  Весна — распутица и змеи; лето — зной, грозы, жатва и болотная лихорадка (раны не заживают,
  лечат отвар или священник); осень — сбор винограда, кабаны, туманы и дожди.
- Работа по сезону: жатва летом, виноград в сентябре–октябре, хворост осенью и зимой, травы весной
  и летом. Зерно дорожает весной и дешевеет после жатвы, вино — после сбора винограда.
- Погода меняется каждые несколько часов: ясно, пасмурно, дождь, гроза, туман, снег, метель, зной.
  Дождь и туман сужают обзор, непогода и распутица замедляют путь, мокрая тетива бьёт хуже
  (арбалету почти не мешает), в зной тяжёлый доспех изматывает. Капли и снег видны на карте.
- Жители говорят о погоде и заботах сезона.

**Еда и усталость**
- Сытость (0–100) тает примерно за полтора дня. Голодный не заживает и хуже бьётся,
  изголодавшийся теряет здоровье. Усталость копится за сутки на ногах — быстрее с тяжёлой
  поклажей и в горах, медленнее верхом по дороге; уставший хуже бьёт и уворачивается, медленнее идёт.
- Провиант (паёк на день, 4 мон.) продают трактирщики, купцы и старосты деревень; `T` — поесть.
  Нет провианта — герой ест из товара: сыр, зерно, масло, вино.
- В трактире — горячая еда (полная сытость и немного здоровья), в монастыре — трапеза с братией за лепту.
- Сон: комната в трактире — лучший; лагерь на карте Италии (`R`) — могут напасть; ночлег в глуши
  на местной карте (`R`) — костёр и плащ, но может подойти зверь, а в холод без огня продрогнешь.
  На голой земле до конца не выспишься. В городе на мостовой спать нельзя — стража погонит.

**Стрельба и метание**
- `F` — выстрелить из того, что в правой руке; цель выбирается сама (ближайшая на линии огня),
  `Tab` — следующая. Стены и другие твари загораживают выстрел. Точность — от Ловкости и расстояния.
- Праща (у пастуха-горца с самого начала, у кузнецов — за 12 мон.; камней вдоволь), охотничий и длинный лук (длинному нужна Сила 8),
  арбалет и генуэзский арбалет — бьют сильнее и точнее, но после выстрела их надо взводить (1–2 хода).
- Без стрелкового оружия `F` метает дротики или метательные ножи (урон растёт от Силы).
- Стрелы, болты и дротики продают кузнецы и купцы; часть выпущенных можно подобрать там, где они упали.

**Лошадь и мул**
- Покупаются у трактирщиков (лошади — не в деревнях); старое животное идёт в зачёт.
- Лошадь почти вдвое ускоряет путь по дорогам и равнинам, но в горах и болотах проку от неё нет.
  Ей нужен мешок зерна на два дня — или ночлег в остерии с конюшней. Голодная лошадь еле плетётся,
  а на пятый день без корма падает.
- Мул медленнее, зато твёрдо ступает в горах, везёт +30 груза и кормится сам.
- Ночью (с 22 до 6) улицы пустеют: горожане по домам, монахи по кельям. На месте — стража, трактирщик
  и особые гости; изредка бродит полуночник. Утром люди возвращаются.
  У кого свой дом — хижина, кузница, церковь, дом старосты, — тот спит в нём: его видно, можно разбудить
  (спросонья не рады). В деревне и бездомные ночуют по хижинам.
- Вести идут, как в XIII веке: за пределы своей земли (Италия, Гельвеция, Карантания, юг Франции) выходит лишь то,
  о чём знает весь христианский мир, — папа и император, поход короля Людовика, татары, падение Виттории, — и лишь
  с купцами, трактирщиками, клиром и стражей, с опозданием (вёрст тридцать пять в день: из Пармы в Тулузу — недели три).
  У каждой земли — свои вести по датам: смерть последнего Андекса, Цюрих против интердикта, Карл Анжуйский уходит в поход,
  король строит Эг-Морт. В чужих землях жители говорят и о своей поре года — сенокосе, перевалах, мистрале, вайде.
- Не всякий интересуется вестями: каждый третий крестьянин, ремесленник или травница живёт своим хозяйством
  и на «Что нового?» отмахивается. Трактирщик, купец, корабельщик, стража, священник и староста — люди при вестях.
- В деревнях тропа к краю карты обходит дома, а от двери каждого дома к тропе или площади протоптана тропинка.
- Шайки разбойников держатся трактов: логово — в двух-трёх клетках от дороги, без добычи сидят в засаде. Почуяв путника (за 8 клеток, но не у самых поселений), идут по пятам и нагоняют. После стычки в округе затишье на день-три; новая шайка приходит издалека, а не возникает рядом. В среднем — одно нападение на неделю пути; на юге шайки ловят королевские дозоры. От погони уйти трудно: кто гонится и близко,
  тот настигает (ловкость и атлетика помогают оторваться).
- Ночлег в глуши опасен: костёр видно издалека. Чаще всего нападают в лесу, на болоте и в горах, вдали от жилья
  (примерно каждая пятая-шестая ночь), реже — в поле, у дороги и под стенами. Шайка, что бродит рядом, приходит на огонь;
  ночью к костру подбирается и вор — чуткий (Мудрость, выживание) проснётся, остальные недосчитаются монет или провианта.
  Бывалый путник выбирает место лучше; печать или святой-покровитель хранят ночлег.
- Ночью в лагере животное могут увести. Перегруженный путник тащится по карте в полтора раза дольше.

**Торговля**
- Окно торговли: слева товары торговца, справа твоя поклажа и трофеи (`Enter` — одна штука, `A` — всё).
- Тринадцать товаров эпохи: зерно, вино, оливковое масло, соль, сыр, шерсть, сукно, железо, пряности, шёлк,
  и мальтийские — хлопок, тмин и мёд.
  Где товар производят (сицилийское зерно, сардинская соль, флорентийское сукно, железо Брешии и Эльбы,
  пряности Венеции и Генуи, шёлк Лукки и Палермо), там он дёшев; чем дальше — тем дороже.
  Цены ещё и гуляют от недели к неделе, а запасы у торговцев пополняются со временем.
- У купца на прилавке не всё сразу: своё, здешнее — всегда, привозное — когда довезли. Чем дальше
  производитель и чем меньше город, тем реже; привоз меняется раз в неделю. Хлеб, вино и соль возят
  повсюду, а пряности, шёлк и тмин держат лишь большие города и порты. В городе — около 9 товаров из 13,
  в городке — около 7. Покупают купцы любой товар; на ярмарке есть всё. Пришёл большой караван — товар появляется.
- Дёшево или дорого — видит только опытный торговец (торговля 3): у него цены подсвечены
  и известна обычная цена товара. Новичок торгует вслепую. Что производят в городе или селе — спроси у местных
  («Чем славятся ваши края?») — услышанное записывается в журнал слухов. Сама лавка ничего не подсказывает.
- Купцы стоят на рыночных площадях городов. Совет, где торговать, — их хлеб: один поделится, другой — если разговорить или если ты у него покупал, третий промолчит; советуют раз в день, услышанное — в журнал. Трактирщики торгуют едой
  и скупают трофеи, травницы продают отвары и дороже берут яды, мази и прочую алхимию,
  старосты деревень продают местные припасы.
- Унести можно столько, сколько позволяет Сила (`20 + Сила × 4` мест).

**Гвельфы и гибеллины**
- Италия 1247 года расколота: гвельфы держат сторону папы (Милан, Генуя, Болонья, Флоренция, Парма, Рим…),
  гибеллины — императора (Кремона, Павия, Верона, Пиза, Сиена, всё Королевство Сицилия). Венеция и острова в стороне.
  На карте при осмотре города видно, за кого он.
- 2 февраля 1248 года Флоренция становится гибеллинской — как и было.
- По северу и середине Италии ходят отряды: синие `W` — гвельфы, золотые `W` — гибеллины.
  Идут в набег на вражеские земли или на подмогу своим. С ними можно поговорить — «За кого воюете?».
- Встретившись, враждебные отряды иногда бьются (крупная стычка — примерно раз в две недели).
  Рядом слышен звон железа; о бое начинают говорить в округе.
- На месте боя дней пятнадцать лежит поле: павшие, знамёна, брошенное оружие и доспехи, монеты,
  вороньё — и мародёры, которые пришли раньше тебя. Поле надо отыскать самому.

**Алхимия**
- Травы растут в глуши (`ψ`, у каждой свой цвет; наведи — название): подорожник, ромашка, шалфей, рута,
  зверобой, полынь, мята. У каждой свои места (луга, холмы, топи, лес) и месяцы; зимой в поле пусто.
  Наступи на траву — сорвёшь (Выживание иногда даёт два пучка). Сушёные травы держат травницы.
- Алхимии надо научиться. Алхимиков мало: на всю Италию их от 4 до 9 — в больших городах и изредка в городках,
  а иногда попадаются в глуши — ищут травы и камни. Учат за плату и только грамотных (рецепты пишут по-латыни).
  Грамота упирается в ум: выше «Мудрость − 5» не выучишься (Мудрость 6 — грамота 1, 7 — 2, 8 — 3).
  Ученик сразу знает целебный отвар и ранозаживляющую мазь.
- Особый рецепт — **отвар великана** (мозг из кости великана, зверобой, шалфей; котелок). Его не продают
  и не найти в свитках — только догадаться самому (на Мальте об этом шепчутся). На 6 часов: +3 к урону,
  +2 к защите, +20 к грузу; когда сила уходит — тяжёлая усталость.
- Остальные рецепты покупают у алхимика или находят в свитках — в тайниках, у чернокнижников, в кладах.
  Свиток прочтёт только грамотный, понять — только знающий алхимию; до тех пор он лежит в котомке.
- Рецепт можно открыть и опытным путём: положи верный состав в нужный инструмент — если выйдет, рецепт запомнится.
  Сорвалось на неизвестном рецепте — варево «почти получилось»: значит, состав верный, пробуй ещё.
- Даже знакомое зелье может не выйти (перекипело, пригорело, не та мера) — реагенты пропадают.
  Шанс неудачи зависит от сложности зелья (мазь — 20%, отвар — 25%, противоядие — 40%, aqua vitae — 55% у новичка),
  для неизвестного рецепта он на 15% выше, а каждый уровень «Алхимии» снижает его на 6% (но не ниже 3%).
  В окне алхимии у каждого рецепта видно «удача N%».
- Инструменты (ступка, котелок, перегонный куб) продают алхимики.
- Окно алхимии (`A`): слева реагенты, в середине инструменты, справа известные рецепты. Кладёшь реагенты кликом
  (или ↑↓ Enter), вынимаешь кликом по реагенту в инструменте, «Сварить» — пробел; клик по рецепту раскладывает его сам.
  Не тот состав или не тот инструмент — бурая жижа, реагенты пропали.
- Зелья: целебный отвар, противоядие (полдня яд не берёт), бодрящий настой, отвар от лихорадки, ранозаживляющая мазь,
  масло зверобоя (полдня +3 урона по нечисти), aqua vitae (перегонный куб, вино).
- Навык «Алхимия» растёт от варки и иногда даёт две порции. Предыстория «Ученик аптекаря»: уже владеет алхимией,
  знает три рецепта, со ступкой, котелком и травами.

**Прицельные удары** (пробная механика; выключается в отладке, F9 → «Прицельные удары»)
- Прицел — режим: «корпус / голова / руки / ноги» (`V` или клик по строке «Прицел» на панели героя).
  Все удары и выстрелы идут туда, пока не сменишь. Для стрельбы штраф снижает навык стрельбы; стрела оглушает реже дубины.
- Голова: −5 к меткости, урон ×1,25, может оглушить (враг пропустит ход); шлем у врага гасит удар и оглушение.
  Руки (лапы): −2, урон ×0,9, враг 3 хода бьёт на четверть слабее. Ноги: −2, урон ×0,9, враг 3 хода хромает
  (теряет каждый второй ход). Увечья ложатся не с каждого удара; крупные твари стойче.
- Навык оружия снижает штраф к меткости. Булава и дубина оглушают вдвое чаще, топор чаще калечит,
  рогатина точнее в корпус, нож и кинжал исподтишка в голову — ещё больнее.
- Строение у существ разное: у людей все четыре зоны, у зверей голова, корпус и лапы, у змей и пауков — голова и тело,
  у летучих и бесплотных — только тело. В бестиарии — «Куда бить».
- Твари тоже бьют по зонам: змеи и крысы — по ногам, вороньё — в лицо, волк — в бок и по ногам, человек — куда придётся
  («Разбойник бьёт тебя дубьём в голову: −5»). Часть доспеха защищает всё тело (щит, общий вес брони, реликвии),
  часть — только свою зону: шлем — голову, наручи — руки, поножи и сапоги — ноги. Без шлема тяжёлый удар в голову
  может оглушить героя.
- По прогону: против толпы выгоднее корпус, против одного крупного зверя или чудовища — голова,
  против латников в шлемах — корпус или ноги. Ни одна зона не лучше всегда.

**Города**
- Застройка плотная: дома слеплены в сплошные ряды с общими стенами, между рядами — узкие переулки, садов внутри стен мало.
  Дом посреди ряда без выхода на улицу становится задними комнатами соседа.
- Размер — по населению около 1247 года: Венеция, Милан, Флоренция, Генуя — крупнейшие; Пиза, Верона, Бари, Мессина — меньше;
  городки — от крохотных Кальви и Тренто до Сиены и Кремоны (втрое больше). В каждом — церковь, палаццо, остерия, кузница и травница.
- За воротами вдоль дороги — предместья (borgo): дома бедноты, огороды, сено, телеги, дворы ремесленников с чанами.
- Города, уже построенные в старом сохранении, остаются как были; новое — в новых играх и в ещё не виданных городах.

**Монастыри**
- В каждой обители есть брат-библиотекарь. Он покупает книги (их находят в тайниках, кладах, у чернокнижников:
  «Канон» Авиценны, «Этимологии» Исидора, Боэций, Вегеций, евангелие лангобардского письма…) и свитки с латынью,
  которые сам не понял, — торговцы книг не берут. Платит за день в скриптории (нужна грамота; растёт грамота),
  пускает почитать (алхимик может найти в травнике рецепт). Так и без магии книги и свитки — хороший заработок.
- У аббата — исповедь раз в неделю: благочестие и тишина вокруг дурной молвы.
- У знаменитых обителей своё лицо и своя служба: Монтекассино — больница братьев (лечат даром раз в неделю);
  Ассизи — братья бедны, книги берут дёшево, зато дают хлеб, а 1–2 августа — прощение Порциункулы;
  Бобьо — лучшая библиотека, платит за книги дороже всех; Помпоза — певчие брата Гвидо (благодать);
  Монте-Сант-Анджело — пещера Архангела (благочестие, милость Михаила); Фарфа — имперское аббатство,
  аббат заступится перед инквизицией; Сакра-ди-Сан-Микеле — даровой ночлег для путников на перевале.

**Инквизиция**
- Дурная молва растёт от тайной науки (учение, печати, колдовство при людях), от языческого на глазах набожных,
  от таинства Митры. Стихает сама (раз в десять дней), быстрее — после исповеди у аббата или заступничества Фарфы.
  Когда молвы много, в панели героя — «О тебе шепчутся».
- В гвельфских городах и Папской области героя тогда может ждать доминиканец брат Пьетро из Вероны
  (исторический проповедник против катаров). От разговора не уйти: покаяться (обереги в огонь, штраф, молва — в ноль),
  «я добрый христианин» (красноречие и благочестие), «пожертвование на обитель» (подкуп — может не выйти)
  или бежать (скрытность, атлетика; удалось — молва растёт, слава падает; нет — ночь в подвале и покаяние вдвое).
  В землях императора и в Лючере инквизиторам воли нет; сарацина их суд не касается.

**Пропавшая книга Леонардо** — учёный квест
- В Пизе живёт старик Леонардо, сын Боначчи (Фибоначчи): тот, кто принёс в Европу индийские цифры с нулём.
  По Тоскане и Лигурии ходит слух: у мастера пропала книга. Его «Di minor guisa» о торговом счёте и в самом деле утрачена.
- След: вдова генуэзского купца → нотарий, составлявший опись (заплатить, уговорить красноречием или прочесть
  протокол самому — грамота 2) → библиотека аббатства Бобьо. Там книгу выкупают даром аббатству, отрабатывают три дня
  в скриптории (грамота 2; растёт грамота и благочестие) или крадут ночью (скрытность; попался — дороже, второй раз — не пустят).
- Награда: деньги, опыт, слава, рост торговли и грамоты, рекомендательное письмо (у торговцев −5%)
  и уроки счёта у мастера (торговля).

**Поход короля Людовика (1247–1248)** — то, что готовится у всех на глазах
- Король Франции принял крест ещё в 1244-м; генуэзцы строят ему корабли, папа велит проповедовать крест —
  и против сарацин за морем, и против самого императора. Игра идёт по настоящему календарю:
  - **осень 1247**: на генуэзских верфях закладывают нефы — железо в Генуе дорожает почти вдвое, сукно и шерсть тоже;
    в больших гвельфских и вольных городах на площадях проповедуют крест (можно послушать и пожертвовать на поход),
    в гибеллинских — проповедников хватают;
  - **зима 1248**: Фридрих обещает Людовику сицилийский хлеб — на Сицилии и в Апулии зерно дорожает;
  - **весна и лето 1248**: с Альп спускаются отряды крестоносцев `+` и идут по дорогам севера к Генуе;
    в генуэзской гавани — нефы под французскими флагами;
  - **12 июня** король берёт орифламму, **25 августа** флот генуэзских адмиралов Уго Лерчари и Якопо ди Леванте
    уходит за море, **17 сентября** — высадка на Кипре. Большие вести долетают до героя, где бы он ни был.
- Слухи меняются вместе с порой: от «король поплывёт в Египет» до «на Кипре у короля мрут люди от лихорадки».

**Узник Эццелино** — квест для прославленного героя (слава 40+)
- Эццелино да Романо, викарий императора и самый жестокий тиран своего века, держит Верону, Падую и Виченцу
  и бросает в тюрьмы гвельфскую знать. Прославленного героя в любом городе догоняет гонец с письмом
  от мессера Альдригетто, родича изгнанных графов Сан-Бонифачо: его сына Тебальдо схватили с письмами
  к изгнанникам, через 20 дней его повесят у Арены. Тебальдо — в тюрьме замка Сан-Пьетро за Адидже.
- Четыре пути:
  1. **Под личиной.** Выкупить (или стащить) у пьяного латника в остерии сюрко с чёрным орлом — и войти
     в ворота как свой. Тюремщики не трогают, пока не заподозрят: не стой рядом с ними и не медли.
     Решётку тебе отопрут сами — «велено привести узника наверх».
  2. **Силой.** Перелезть стену и пробиваться: пять тюремщиков и их начальник Гуэцелло.
  3. **Тайно.** Расспрашивать веронцев (лучше — лодочников на Адидже) о замке, пока кто-нибудь не вспомнит
     старый римский сток. Ночью по нему — в подвалы, пока стража спит; ключи — в караульной.
     Неосторожные расспросы пугают людей — и стражу удваивают.
  4. **Донести самому Эццелино** в его палаццо: деньги — и смерть отца с сыном на твоей совести.
- Награда за спасение: деньги, опыт, слава и перстень Сан-Бонифачо (гвельфские купцы уступают в цене).
  Не успел за 20 дней — Тебальдо казнят.

**Тайная наука (герметизм)**
- Учёная магия XIII века — не огненные шары, а звёзды, планетарные часы и печати на металле
  (Изумрудная скрижаль, «Асклепий», Сабит ибн Курра «О талисманах», арабский «Пикатрикс»).
- Учат двое: магистр Феодор Антиохийский, философ и звездочёт Фридриха II (в Виттории при императоре,
  после её падения — в Кремоне), и мудрец Абу-ль-Касим в Лючере. Нужны Мудрость 7 и грамота 2.
  Каждый учит двум своим печатям и двум операциям; второй учитель доучит операциям за полцены.
- Часы планет: день (от восхода до заката) и ночь делятся на 12 неравных часов; первым часом дня правит
  владыка дня недели (воскресенье — Солнце, понедельник — Луна…), дальше — по халдейскому порядку
  Сатурн → Юпитер → Марс → Солнце → Венера → Меркурий → Луна. В окне (`Z`) видно, чей час сейчас и какие дальше.
- Печать надо знать. Феодор учит печатям Солнца и Меркурия и продаёт печать Юпитера, мудрец — Сатурна и Марса,
  продаёт печать Луны (чужие печати и проданные — дорого и не новичку: герметика 2). Печать Венеры есть только
  в старых трактатах — листы находятся в тайниках и кладах; прочтёт посвящённый с грамотой 2.
- Талисман режут на металле планеты в её день и её час (Марс — во вторник в час Марса) и при ясном небе
  (не под землёй, не в тучи) — окно бывает несколько часов в неделю. Металл дорог (свинец и железо 25, олово и медь 40,
  ртуть 70, серебро 90, золото 180), резец срывается часто (у новичка 6 раз из 10). Весь набор — месяцы. Носится в слоте реликвии: Сатурн (свинец) — защита +1, Юпитер (олово) — слава +25%,
  Марс (железо) — урон +1, Солнце (золото) — Живучесть +1, Венера (медь) — цены ниже, Меркурий (ртуть) — Мудрость +1,
  Луна (серебро) — ночью видно дальше.
- Операции (Феодор): «Свет Солнца» (зверобой: шесть часов светло, +3 света под землёй), «Вопросить звёзды»
  (ночью при ясном небе, раз за ночь: укажет скрытый слух или гробницу поблизости).
  Операции (мудрец): «Печать Сатурна» (рута: полсуток звери и разбойники обходят — в пути и на ночлеге),
  «Узы Марса» (полынь: ближайший зверь скован на 6 ходов, нечисть может вырваться).
- Ресурса нет: цена — время, усталость, травы, металл. Навык «Герметика» снижает шанс срыва.
- Цена для души: учение, резьба печатей и операции снижают благочестие; у святых Михаила и Бенедикта это нарушение обета.
- Языческое на шее (талисманы, горгонейон, булла) само по себе благочестия не отнимает — пока его не увидит набожный:
  священник, монах, отшельник, паломники, нищенствующие братья. Увидел — укор и −2 благочестия за каждую вещь
  (раз в день на человека). Купцу и стражнику всё равно.

**Карта**
- Местность читается пятнами: у каждой — мягкая заливка фона (луга тёмно-оливковые, поля охристые, лес тёмно-зелёный,
  холмы бурые, горы серо-каменные, топи бирюзовые, вода синяя). Дороги — светлые полосы, их не спутать с реками.
  Города, места, подписи и путники — на тёмной подложке, чтобы выделялись. Ночью всё темнеет вместе.
  Увиденное раньше в глуши и подземельях видно чуть ярче. Дождь на карте Италии реже и тусклее.

**Графика**: по умолчанию карта нарисована простыми картинками (деревья, ели, холмы, горы со снегом, волны, колосья,
стены, двери, домики, замки); герой и путники — фигурки, звери и люди — круглые фишки своего цвета со своей буквой.
`G` — переключить на классические символы и обратно (выбор помнится). Адрес с `?ascii` или `?tiles` — принудительно.
В городах и подземельях свои картинки: мостовая, дощатый пол, плиты склепа, колонны, алтари, колодцы, купели, полки,
столы, кровати, лестницы, саркофаги, сундуки, бочки, урны, костры, палатки, кости, могилы, троны, лотки, корабли.
Пашни и виноградники лежат пятнами вокруг городов, деревень, замков и монастырей — не посреди глуши и не вдоль каждой дороги.
Подписи на карте — только у трёх ближайших мест (большой город — в пределах 12 клеток, городок — 8, деревня — 4);
остальные названия — наведением мыши.
Разглядеть мышью можно только то, что в пределах взгляда: днём на карте Италии — около десяти клеток, ночью — три,
в тумане и дожде меньше; на местной карте — как далеко видит герой.

**Бестиарий — 66 существ**
- Чудовища — по-настоящему жуткие враги: орко, киклоп, тени-хозяева гробниц, морской змей, змей Тарантазио.
  На 5-м уровне с хорошим снаряжением бой с ними — серьёзный риск, и только к 8-му — уверенная победа.
- Звери: заяц, лиса, благородный олень, альпийский козерог, муфлон, кабан, апеннинский волк,
  бурый медведь, буйвол, гадюка, тарантул, ворон, крыса, летучая мышь, одичалый пёс.
- Нрав правдоподобный: вороны, крысы и летучие мыши на здорового путника не бросаются и в пути не нападают.
  Вороньё слетается клевать ослабевшего (здоровья меньше трети), загнанная или раненая крыса кусается,
  а в склепах и подземельях голодные крысы и нетопыри нападают сами.
- Люди: разбойник.
- Дивные: монаккьелло (крадёт монеты), маццамурелло (кидается камнями), фоллетто,
  джанас (убить — грех), сальван, ангуана и сирена (заманивают пением).
- Нечисть (только ночью): блуждающий огонёк, упырь, неупокоенная душа (высасывает благодать),
  чёрный пёс, стрега, сурбиле, ламия, лупо маннаро.
- Чудовища: орко и змей Тарантазио.
- У зверей свои края: тарантулы — в Апулии, муфлоны — на островах, медведи — в Альпах
  и Абруццо, сирены — на берегах юга. Бестиарий подсказывает, где искать ещё не встреченных.
- Бестиарий (`X`) — книга «Liber bestiarum»: оглавление с главами (Звери, Люди, Дивные, Нечисть, Чудовища),
  у каждой главы — вступление и счёт записей. В главе слева список, справа запись; `←→` листают главы,
  `Esc` — к оглавлению. Всё работает и мышью: вкладки глав, стрелки ‹ ›, клик по записи. Новая глава появляется сама, когда у существ появляется новая категория.

## Управление

**Мышью:** клик по клетке — идти туда (герой сам обходит препятствия и останавливается, если
увидит зверя или его ранят); клик по жителю — подойти и заговорить; по зверю — ударить, если он
рядом, или выстрелить, если в руках лук или праща; по алтарю, сундуку, саркофагу, лестнице —
подойти и воспользоваться. На карте Италии клик — проложить путь (остановка у поселений и мест
из слухов по дороге), клик по себе — войти. При наведении всплывает подсказка: что за место,
зверь (здоровье, повадки) или житель. Правый клик или любая клавиша — остановиться.

Справа — панель героя: полоски здоровья, благодати и опыта, характеристики, оружие и запасы,
дата, погода, место, активные состояния (яд, лихорадка, благословения, милость святого) и задания.
Снизу — журнал сообщений с прокруткой и вся история, рядом — кнопки действий с клавишами.

Окна — оформленные, поверх карты, и всё в них работает и мышью, и клавишами:
- **диалог** — портрет жителя (миниатюры в духе готических рукописей XIII века: медальоны на
  синем и красном фоне с сеткой, тонкий контур, приглушённые темперные цвета; для каждой роли; крестьяне — по шесть мужских
  и женских лиц, горожане — по шесть,
  у купцов два лица),
  реплика и варианты ответа кнопками;
- **котомка** — фигура героя со слотами, мешок, товары, трофеи и поклажа; карточка предмета
  со сравнением с надетым («+2 урон, −1 уклонение»); двойной клик — надеть;
- **торговля** — две колонки, цвет цены (выгодно / обычно / дорого), кнопки «купить», «продать», «всё»;
- **журнал** — вкладки «Задания», «Слухи», «Календарь»: список, подробности, сетка месяца и праздники;
- **лист героя** — характеристики с кнопками «+», показатели, вера, народ;
- **молитвы** — карточки молитв и чудо святого.
Клик мимо окна или ✕ — закрыть.

**Клавиатурой:**

| Клавиша | Действие |
|---|---|
| Стрелки, NumPad, `H J K L Y U B N` | ходьба (на зверя — атака; перед жителем — остановка, ещё шаг — разговор) |
| Ё (`` ` ``) или F9 | **режим отладки**: характеристики, уровень, деньги, благочестие, покровитель, любой предмет, бессмертие; перенос в любое место, открыть все места, спуск на уровень ниже, показать ловушки и тайники, перемотка времени, любой зверь рядом; стадии сквозных заданий |
| Пробел, `.`, NumPad 5 | ждать ход (в подземелье — ещё и обыскать стены вокруг) |
| `P` | молитвы и чудо святого; шаг на алтарь — молитва у алтаря |
| `F` | стрелять / метать (`Tab` — другая цель, `Enter` или `F` — огонь) |
| `Q` | выпить отвар |
| `R` | в глуши — заночевать; в пути — лагерь; в городе — передохнуть |
| `T` | поесть (провиант или товар) |
| `C` | лист персонажа и повышение характеристик |
| `I` | снаряжение и котомка |
| `X` | бестиарий |
| `A` | алхимия |
| `Z` | тайная наука (звёзды, талисманы) |
| `V` | прицел в ближнем бою (пробная механика) |
| `G` | карта: картинки или символы |
| `M` | атлас (`Tab` — другой лист) |
| `Ж` (`;`) / `O` | журнал: задания, слухи, календарь |
| `Enter` / `E` | войти в город, осмотреться — или выйти на карту Италии |
| `S` | сохранить игру |
| `?` / `F1` | справка |

Команды привязаны к физическим клавишам, поэтому работают и на русской раскладке.
На сенсорных экранах появляются экранные кнопки.
