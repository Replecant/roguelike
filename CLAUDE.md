# Anno Tenebris — заметки для работы над игрой

- Отвечать автору по-русски. Год — 1247: историческая точность (сомнительное — смягчать), погружение, серьёзный тон, без современных примет.
- После каждой доработки: `node tests/run.js` → коммит в main и push → `npm run build` → опубликовать dist/anno-tenebris.html.
- Скрипты подключаются по порядку в index.html; новые файлы — ещё и в tsconfig.json (`npx tsc -p .`).

## Новая земля (defineLand в content/<земля>/land.js)

Каждой земле — свой характер, не только суша и города:
- `style` — из чего строят и чем кроют (js/townstyle.js: кирпич, известняк, базальт, дерево, побелка, глина, сланец, охра);
- `layout` — как стоят дома: город (`grid` сетка с аркадами, `hill` на холме, `lanes` проулки с двориками) и село
  (`street` вдоль дороги, `scattered` хутора); `null` — обычная застройка;
- `wild` — какая здесь глушь (js/wildlands.js: степь, маквис, гаррига, альпийские луга, дремучий лес, ланды…);
- свои имена, речи, слухи, звери с местными названиями, дозор, товары, руины, лист атласа.
Тест «Земли из реестра» не пропустит землю без `style`, `layout` и `wild`.

## Проверка генерации

- `node tools/audit-gen.js N` — проходимость, двери, колодцы, мосты, пашни, пригороды (по N мирам);
- `node tools/audit-cities.js city,town` — реки и мосты, одинокие колонны, странные дома;
- сохранённые карты при загрузке строятся заново по генератору (+ правки поверх), поэтому новое в генерации —
  только для новой версии: поселения — `city.genV` (сейчас 6), места событий — `lead.wildV` (сейчас 2).
